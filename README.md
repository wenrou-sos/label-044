# 🏃 3D 跑酷游戏 - Endless Runner

一款基于 Three.js 开发的纯前端 3D 无尽跑酷游戏，开箱即用，无需额外安装依赖。

---

## 🎮 游戏玩法说明

游戏中，玩家控制一个角色在三条跑道上自动向前奔跑，需要通过左右切换跑道和跳跃来躲避前方的障碍物，同时收集金币获得额外分数。随着游戏进行，速度会逐渐加快，难度不断提升。

### 核心玩法元素

- **三条跑道系统**：角色可以在左、中、右三条跑道之间自由切换
- **障碍物**：包含普通方块、高柱子、低矮平台等多种类型
- **金币收集**：收集金币可获得额外 10 分
- **渐进式难度**：速度、障碍物密度随游戏进程自动提升
- **得分机制**：基础分数 = 奔跑距离 × 0.5 + 金币数 × 10

## ⌨️ 操作方式指南

### 键盘操作

| 按键 | 功能 |
|------|------|
| `←` / `A` | 向左切换跑道 |
| `→` / `D` | 向右切换跑道 |
| `↑` / `W` / `空格` | 跳跃 |
| `P` / `ESC` | 暂停 / 继续游戏 |
| `空格` / `Enter` | 开始游戏 / 重新开始 |

### 触屏操作（移动端）

| 手势 | 功能 |
|------|------|
| 向左滑动 | 向左切换跑道 |
| 向右滑动 | 向右切换跑道 |
| 向上滑动 | 跳跃 |

### UI 按钮

游戏界面右上角提供 ⏸️ 暂停按钮，可随时暂停游戏。

## 🚀 本地启动步骤

### 方式一：直接打开（推荐）

由于项目使用纯前端技术栈，所有资源均通过 CDN 加载，可直接运行：

1. 双击打开 `index.html` 文件
2. 即可开始游戏！

### 方式二：使用本地 HTTP 服务器（更稳定）

如果遇到浏览器跨域限制，可以启动本地服务器：

#### 使用 Python
```bash
# Python 3
python -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080
```

#### 使用 Node.js (npx)
```bash
npx serve .
```

#### 使用 VS Code
1. 安装 "Live Server" 插件
2. 右键 `index.html` → "Open with Live Server"

启动后在浏览器访问 `http://localhost:8080` 即可。

## 🧩 核心功能实现思路

### 1. 角色系统与动画

- **角色模型**：使用 Three.js 基础几何体（球体、立方体）组合成一个拟人化角色，包含头、身体、手臂和腿部
- **奔跑动画**：通过 `Math.sin(runTime)` 计算四肢摆动角度，实现循环奔跑动画
- **跳跃动画**：跳跃时切换为固定的跳跃姿势（双臂后摆，双腿微屈）
- **平滑移动**：角色在跑道切换时使用插值（lerp）实现平滑过渡

### 2. 控制机制

- **三跑道系统**：定义 `LANES = [-2, 0, 2]` 三个固定 X 坐标位置
- **跳跃物理**：使用简单的重力加速度模型，`jumpVelocity` 随时间递减，到达地面时复位
- **输入响应**：键盘事件使用 `keydown` 监听，支持 WASD 和方向键；触屏支持滑动手势识别

### 3. 障碍物与生成系统

- **对象池**：障碍物在 Z = -80 处生成，随游戏推进向摄像机移动，Z > 15 时销毁并释放资源
- **多样化障碍**：三种类型（普通方块、高柱子、低矮平台），随机选择
- **生成节奏**：`spawnInterval` 随距离动态缩短，实现难度递增

### 4. 金币收集系统

- **金币模型**：使用 `TorusGeometry`（圆环）制作金币，添加金色发光材质和点光源
- **旋转动画**：金币在移动过程中持续绕 X 轴旋转
- **收集动画**：被收集时播放缩小上升的动画，并从场景中移除
- **碰撞检测**：基于 AABB 简化碰撞，判定角色与金币的距离阈值

### 5. 碰撞检测系统

- **障碍物碰撞**：检测 X、Z 轴的重叠距离，同时判断 Y 轴是否接触（跳跃可能越过低矮障碍）
- **金币碰撞**：宽松的球形碰撞判定（1.0 距离阈值）提升收集手感
- **碰撞时机**：仅检查 Z 轴附近 ±2 范围内的对象，优化性能

### 6. 计分与难度系统

- **分数计算**：`score = distance × 0.5 + coins × 10`，距离和金币综合计分
- **速度递增**：`speed = min(30, baseSpeed + distance × 0.003)`，距离越远速度越快
- **生成频率**：障碍物和金币生成间隔随距离缩短，提高反应压力

### 7. 游戏状态管理

四个状态机：
- `START`：开始界面，展示操作说明和历史最高分
- `PLAYING`：游戏运行中，主循环正常更新
- `PAUSED`：暂停状态，主循环跳过更新逻辑
- `GAMEOVER`：游戏结束，展示最终得分和新纪录提示

### 8. 本地存储

- 使用 `localStorage` 存储键 `endlessRunnerHighScore`
- 每次游戏结束时比较并更新最高分
- 开始界面和 HUD 实时展示最高分

### 9. 视觉效果与性能优化

- **阴影系统**：启用 PCFSoftShadowMap 软阴影，提升视觉真实感
- **雾效**：场景雾淡化远处物体，同时减少可视范围提升性能
- **星空背景**：使用 Points 粒子系统渲染 500 颗星星
- **背景建筑**：远处楼群使用视差滚动（0.5 倍速度），增强深度感
- **像素比限制**：`Math.min(devicePixelRatio, 2)` 防止高 DPR 设备性能下降
- **材质复用**：相同类型的障碍物/金币共享材质，减少 Draw Call

### 10. 音效系统

- 使用 Web Audio API 实时合成音效，无需外部音频文件
- 跳跃：上升方波扫频
- 金币：双音正弦波（叮咚声）
- 撞击：锯齿波下降扫频
- 游戏结束：下降三音和弦
